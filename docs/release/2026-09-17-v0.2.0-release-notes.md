# HRBPilot v0.2.0

## English

HRBPilot v0.2.0 is a local-first AI workbench for evidence-grounded and governed HR workflows.

### Highlights

- **Task-first MCP + OAuth.** External agents can inspect their effective access, retrieve policy evidence or case context, freeze a draft action, and follow its task status through a standard MCP Streamable HTTP interface with OAuth 2.1 + PKCE.
- **Human approval before side effects.** Write actions are proposals, not direct mutations. Approved work is dispatched through a transactional Outbox and an independent Worker, with input binding, idempotency, audit events, and recovery semantics.
- **Safer knowledge workflows.** Knowledge-base authority tiers, tenant-aware deduplication, retrieval degradation guards, and untrusted-evidence handling make failures explicit rather than fabricated.
- **Verified baseline.** In a complete local dependency environment: 1,008 backend tests passed, 50 environment-gated tests skipped, Ruff and Mypy reported no errors, and web lint, build, and 73 Vitest tests passed.

### Getting started

For personal use on one machine, run Docker Compose and connect an MCP client to `http://127.0.0.1:8001/mcp/tasks`; a public domain is not required. Deployments shared across devices or a team need HTTPS, access controls, backups, and key rotation.

See the [English README](https://github.com/kayon0209/hrbpilot/blob/main/README_en.md), the [3-minute demo](https://github.com/kayon0209/hrbpilot/blob/main/docs/release/2026-09-17-release-demo-and-showcase.md), and the [changelog](https://github.com/kayon0209/hrbpilot/blob/main/CHANGELOG.md).

## 中文

HRBPilot 0.2.0 是一个本地优先的 HR AI 工作台，重点解决“AI 的结论有证据、AI 的行动受治理”。

### 本次重点

- **任务优先 MCP + OAuth。** 外部 Agent 可通过标准 MCP Streamable HTTP 和 OAuth 2.1 + PKCE 查询有效权限、制度证据或案件上下文，冻结动作草稿并跟踪任务状态。
- **副作用前必须人工批准。** 写操作只会形成建议，不直接改业务数据；批准后由事务 Outbox 与独立 Worker 派发，并保留参数绑定、幂等、审计和恢复语义。
- **更安全的知识流程。** 知识库权威性分级、租户去重、检索降级护栏和不可信证据处理，使失败明确可见而不是编造答案。
- **已验证基线。** 完整本地依赖环境下，后端 1008 项测试通过、50 项环境门控跳过；Ruff/Mypy 无错误；前端 lint、构建和 73 项 Vitest 测试通过。

### 开始使用

个人同机使用时运行 Docker Compose，并将 MCP 客户端连接到 `http://127.0.0.1:8001/mcp/tasks`，不需要公网域名。跨设备或团队部署需要 HTTPS、访问控制、备份和密钥轮换。
